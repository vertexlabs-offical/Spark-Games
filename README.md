# ⚡ SparkGames
**600+ Free HTML5 Games** — Orange & Black Themed Gaming Platform

## 🚀 Deploy to Vercel (Free)
1. Go to [vercel.com](https://vercel.com) → Sign up
2. Click **New Project** → Import this GitHub repo
3. Click **Deploy** → Live in 30 seconds!

## 📁 Files
- `index.html` — Full site (600 games, search, categories, ads, 3D UI)
- `sparkgames-logo-final.png` — Site logo
- `sparkgames-favicon.png` / `sparkgames-favicon-sm.png` — Favicon
- `vercel.json` — Vercel config
